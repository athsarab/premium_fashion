# Product image uploads

Add product photography to the category folder that matches `lib/fashion-data.ts`.

Recommended export:
- Product cards: 1600 x 2000 px, portrait 4:5, JPG or WebP
- One product per image, centered with generous breathing room
- sRGB color profile, quality 80-90
- Keep each file under 500 KB where possible
- Use lowercase filenames with hyphens

Current filenames:
- `men/column-coat.jpg`
- `men/studio-overshirt.jpg`
- `women/sculpted-knit.jpg`
- `women/bias-dress.jpg`
- `kids/pocket-overshirt.jpg`
- `kids/weekend-set.jpg`

For a polished catalog, photograph every item with the same crop, background treatment, camera height, and light direction. Do not add text, prices, logos, borders, or collages inside the product image.
